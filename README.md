# Ember & Vine — Restaurant Landing Page

A fully responsive restaurant landing page built with **HTML5, CSS3, and vanilla JavaScript** for the Frontend Internship Task (Advanced level).

## 🔗 Live Demo
_(Add your GitHub Pages / Netlify / Vercel link here after deploying)_

## 🛠️ Built With
- HTML5 (semantic structure)
- CSS3 (Flexbox, Grid, custom properties, media queries, keyframe animations)
- Vanilla JavaScript (no frameworks or libraries)

## ✨ Features
- Responsive navbar with mobile hamburger menu
- Hero section with animated visual
- Animated statistics counters
- Dynamic menu rendering with category filtering (All / Breakfast / Lunch / Dinner / Fast Food / Desserts)
- Special offer section with a live countdown timer
- Services section (Dine-In, Online Ordering, Home Delivery, Event Catering)
- Responsive gallery with a custom JavaScript lightbox (next/prev/close, keyboard support)
- Auto-playing + manual testimonial slider
- Reservation modal with full JavaScript form validation
- Contact section with a validated contact form
- Scroll-to-top button
- Scroll-reveal animations on section entry
- Dark / light mode toggle (bonus)
- Sticky navbar with active-link highlighting on scroll (bonus)
- Preloader (bonus)
